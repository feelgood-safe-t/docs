# 리서치 ② 기존 모의투자 서비스 비교 (기획서 4번 "차별성" 근거)

> 작성 2026-08-29 · ⚠️ 표의 세부 스펙은 각 서비스 페이지에서 최종 확인 필요

---

## 1. 시장 지형 — 기존 모의투자는 3개 계층으로 나뉜다

### ① 제도형 (규제 이수용)
| 서비스 | 성격 | 특징 | 한계 |
|---|---|---|---|
| **KRX 모의거래 시스템** (`sern.krx.co.kr`, 2026-08-19~) | 단일종목 레버리지 이수 의무 | 정규장 + Replay장, 5거래일×1시간 | **HTS 전용(MTS 불가)**, 시간 채우기식 이수, 피드백 없음 |
| KRX 개인 공매도 모의거래인증시스템 (`strn.krx.co.kr`) | 개인 공매도 사전 의무교육 | 동일 구조의 선례 제도 | 동일 |
| KRX 파생상품 모의거래인증시스템 (`trn.krx.co.kr`) | 파생상품 사전 의무교육 | 동일 구조의 선례 제도 | 동일 |

> **중요:** 이미 3개 제도(파생 → 공매도 → 레버리지)가 같은 패턴으로 확장 중.
> = **"모의거래 이수제"는 일회성 규제가 아니라 반복되는 규제 템플릿**이고,
> 우리 서비스의 B2B 시장은 이 템플릿이 확장될 때마다 커진다. ← 기획서 6번(확장성)의 핵심 논거

### ② 증권사형 (마케팅·계좌 유치용)
| 서비스 | 특징 | 한계 |
|---|---|---|
| 미래에셋증권 m.Stock 모의투자 | 국내/해외주식·선물·옵션, 실전과 동일한 주문 화면·시세·뉴스 | **실전 UI 학습이 목적** — 리스크 교육 아님 |
| 한국투자증권 모의투자 | 정기 모의투자 대회, 순위·리워드 | **수익률 랭킹 = 고위험 베팅 유인** |
| 기타 증권사 모의투자 대회 | 상금·경품 | 학습 피드백 없음, 대회 기간 한정 |

### ③ 앱·게임형 (재미·리텐션용)
| 서비스 | 특징 | 한계 |
|---|---|---|
| Vestin (주식·코인 모의투자) | 미국주식 포함, 캐주얼 UX | 교육 커리큘럼 부재 |
| KRX 모의증권투자게임(krxverse) | 학생 대상 교육 게임 | 시나리오 고정, 실제 리스크 체감 약함 |
| 각종 주식게임 앱 | 게이미피케이션 | **성과=재미 구조 → 도박화 위험** |

## 2. 공통 한계 — 5가지 (= 우리의 진입 지점)

| # | 기존 서비스 전체의 공통 한계 | 왜 문제인가 |
|---|---|---|
| **C1** | **실제 종목 · 실제 데이터** 기반 | 종목명을 아는 순간 학습자는 "정답"을 검색한다. Replay 구간은 결과를 이미 안다. **훈련이 아니라 답 맞히기**가 된다 |
| **C2** | **결과(수익률)로 평가** | 운 좋은 도박이 1등을 한다. 잘못된 행동을 강화한다 |
| **C3** | **모두에게 같은 시장** | 손절을 못하는 사람과 과도한 분산을 하는 사람에게 같은 훈련을 준다 |
| **C4** | **피드백이 없다** | 무엇을 왜 잘못했는지 알려주지 않는다. 이수 후 행동이 바뀌지 않는다 |
| **C5** | **시장이 반응하지 않는다** | 내 주문이 시장에 아무 영향이 없다. 급락장에서 "팔리지 않는 경험"을 못 한다 |

## 3. 우리 서비스의 포지셔닝 (2×2)

```
                     과정(행동) 기반 평가
                            ▲
                            │
              [ SAFE-T ]   │
        AI 시나리오 + 가명화 │
        + 과정 인증          │
                            │
  가명/합성 시장 ◄───────────┼───────────► 실제 종목/실데이터
                            │
                            │  KRX 이수 시스템
                            │  증권사 모의투자
                            │  주식게임 앱
                            │
                            ▼
                     결과(수익률) 기반 평가
```

**한 문장 포지셔닝**
> 기존 모의투자가 **"실전 주문 화면에 익숙해지는 곳"**이라면,
> **SAFE-T는 "실전에서 잃을 돈을 미리 잃어보고, 왜 잃었는지 진단받는 곳"**이다.

## 4. 기술적 선행 사례 (우리 접근의 학술적 근거)

| 사례 | 내용 | 우리가 인용할 지점 |
|---|---|---|
| **StockAgent** (arXiv:2407.18957, *When AI Meets Finance: LLM-based Stock Trading in Simulated Real-world Environments*) | LLM 기반 멀티에이전트가 실제 시장에 반응하는 투자자 행동을 시뮬레이션. 외부 요인이 거래 행동·수익성에 미치는 영향 분석 | **"LLM 에이전트를 시장 참여자로 두는 것"은 이미 검증된 연구 방향** — 우리는 이를 *연구 도구*가 아니라 **교육·인증 제품**으로 전환한 것이 차별점 |
| ElizaOS / LangChain 기반 트레이딩 에이전트 (2025~2026) | 에이전트 기반 트레이딩 패러다임 확산 | 기술 트렌드 정합성 |

- StockAgent 논문: https://arxiv.org/abs/2407.18957

> **주의:** 위 사례들은 "AI가 잘 투자하게 만드는" 방향(알파 추구)이다.
> 우리는 반대로 **"AI가 사람을 훈련시키는"** 방향이다. 발표에서 이 대비를 명확히 하면 독창성이 산다.

## 1. 충돌 — 기존 문서를 수정해야 하는 항목

**영향 문서**

### C-2. 시장 데이터: AI 합성 시장 → 실제 과거 데이터 가명화·정규화 재생 ⚠️ **가장 중요**

| | 기존 문서 | spec |
|---|---|---|
| 가격 | 100% 합성, 매 세션 새 시장 | **고정 히스토리 데이터를 정규화·가명화 후 재생** |
| 생성 주체 | AI 에이전트가 내생적으로 형성 | **캔들·시장 데이터는 AI가 생성하지 않음** |
| 시나리오 | 자연어로 자유 생성 | **사전 검수된 목록 안에서 AI가 선택** |
| 시장 반응 | 사용자 주문이 호가에 영향(슬리피지·유동성 증발) | 해당 없음 (주문 자체가 없음) |

**영향 문서 — 자기모순이 생기는 지점**
- `01-research/01-…evidence.md` **표 L3**: *"실제 종목·실제 과거 데이터 Replay → 결과를 이미 아는 구간은 학습 효과 없음"*
- `01-research/02-competitive-analysis.md` **표 C1**: *"이미 결과를 아는 과거 데이터라 의미가 없다"*
- `02-proposal/…v0.6.md` **차별성 D1**: *"정답이 존재하지 않는다"*, **D4**: *"반응하는 시장"*

→ **이 세 곳은 Safe-T가 채택한 방식을 정면으로 비판하고 있다.** 그대로 제출하면 자기 아키텍처를 스스로 공격하는 문서가 된다.

**처리 — 비판의 과녁을 옮긴다**

| 기존 비판 | 수정 후 비판 |
|---|---|
| "과거 데이터 재생은 답을 안다" | **"실제 종목명·실제 날짜를 그대로 노출하는 재생"**이 답 맞히기를 만든다 |
| Safe-T의 답 = 합성 시장 | Safe-T의 답 = **가명화 + 정규화 + 랜덤 시작값 + 과정 채점** |

**replay 방식의 방어 논리(그대로 인용 가능)**
> 종목명·기업명·인물명·날짜·뉴스 원문·절대 가격을 모두 가명화하고 시작가를 랜덤 정규화하므로, 학습자는 어떤 구간인지 검색할 단서를 갖지 못한다.
> 설령 구간을 알아본다 해도 **평가는 방향 적중이 아니라 판단 과정을 채점**하므로 통과를 게임할 수 없다.
> 오히려 실제 시장에서 일어난 사건의 인과 구조를 보존하기 때문에, 합성 데이터보다 **학습 전이(transfer)가 높다.**

D4(반응하는 시장)는 C-1과 함께 **후속 실전형 모드 로드맵**으로 이동한다.

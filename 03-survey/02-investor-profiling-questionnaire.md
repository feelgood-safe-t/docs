# 설문 ② 투자 성향 진단 문항 — 서비스 온보딩 내장용

> **목적:** 사용자 성향·취약점을 프로파일링해 **AI가 맞춤 시나리오를 배정**하기 위한 입력값
> **위치:** 서비스 첫 진입 → 온보딩 (기획서 5.1 "사용자 성향 데이터" / 4.1 계층①에 해당)
> **분량:** 12문항 · 약 90초 · 진행률 바 표시
> **설계 원칙:** 모든 문항이 **시나리오 파라미터 또는 채점 기준선**으로 직접 변환되어야 한다. 장식용 문항 금지.

---

## 온보딩 인트로 카피

```
시장을 만들기 전에, 당신을 먼저 알아야 합니다.

12개 질문에 답하면
AI가 당신에게 필요한 시장을 만들어 드립니다.

정답은 없습니다. 솔직할수록 정확해집니다.
```

**버튼:** `시작하기` · 하단 보조문구: `약 90초 소요 · 개인정보는 수집하지 않습니다`

---

## SECTION A. 경험 프로파일 (3문항)
> → **시장 난이도, 초기 자본, 튜토리얼 개입 수준** 결정

**A1. 투자 경험이 어느 정도인가요?**
| 선택지 | 매핑 파라미터 |
|---|---|
| 아직 해본 적 없어요 | `difficulty=intro`, 튜토리얼 강제, 이벤트 빈도↓ |
| 1년 미만 | `difficulty=basic` |
| 1~3년 | `difficulty=standard` |
| 3년 이상 | `difficulty=advanced`, 이벤트 밀도↑ |

**A2. 다음 중 거래해 본 상품을 모두 골라주세요.** *(복수)*
`국내주식 / 해외주식 / ETF / 레버리지·인버스 / 파생상품 / 가상자산 / 없음`
→ 미경험 상품이 **우선 훈련 대상**으로 배정됨 (레버리지 미경험 → 레버리지 필수 세션)

**A3. 투자로 가장 크게 잃어본 금액은 자산의 몇 % 정도였나요?**
`손실 경험 없음 / 5% 미만 / 5~20% / 20~50% / 50% 이상`
→ 시나리오의 **최대 낙폭(MDD) 강도** 기준선 설정

---

## SECTION B. 위험 감내도 (3문항)
> → **변동성·점프 강도** 결정

**B1. 투자한 돈이 하루 만에 -20%가 되었습니다. 첫 반응은?**
| 선택지 | 프로파일 태그 |
|---|---|
| 즉시 전량 매도한다 | `panic_seller` |
| 일부만 정리하고 지켜본다 | `balanced` |
| 그대로 둔다 | `hold_bias` |
| **더 산다** | `averaging_down` ← 물타기 성향. **하락 지속 시나리오 우선 배정** |

**B2. 다음 중 어느 쪽이 더 견디기 어렵나요?**
- 3개월 동안 -30%까지 떨어졌다가 회복하는 것
- 1년 내내 ±3% 안에서 아무 일도 없는 것
→ 후자 선택 시 `boredom_intolerant` — **횡보 구간 인내 훈련** 배정 (변동성 잠식 체감에 최적)

**B3. "원금 손실 가능성이 없다면 수익률이 낮아도 괜찮다"**
`전혀 아니다 1 ─ 2 ─ 3 ─ 4 ─ 5 매우 그렇다`
→ `risk_appetite` 스코어 (1~5)

---

## SECTION C. 의사결정 습관 (3문항) — **채점 기준선의 핵심**
> → 이 3문항이 디브리핑에서 **"당신은 이렇게 답했는데, 실제로는 이렇게 했습니다"** 대조에 쓰인다

**C1. 매수하기 전에 "얼마까지 떨어지면 팔겠다"를 정해두시나요?**
`항상 정해둔다 / 가끔 정한다 / 마음속으로만 / 정하지 않는다`
→ **선언한 손절 습관 vs 실제 손절 준수율**을 대조하는 기준선. *(디브리핑에서 가장 강력한 문장을 만들어내는 문항)*

**C2. 한 종목에 넣는 최대 비중은 보통 몇 % 정도인가요?**
`10% 이하 / 10~30% / 30~50% / 50% 이상 / 정해두지 않는다`
→ **포지션 사이징 기준선**

**C3. 투자 판단을 내릴 때 가장 크게 의존하는 정보는?**
`재무·실적 지표 / 차트·기술적 분석 / 뉴스·공시 / 커뮤니티·SNS 여론 / 지인 추천 / 직감`
→ 뉴스·커뮤니티 의존형은 **가상 뉴스 이벤트 밀도↑ 시나리오** 배정 (확증편향 훈련)

---

## SECTION D. 관심사 및 목표 (3문항)
> → **가명 종목 유니버스의 섹터 구성**과 시나리오 서사 결정

**D1. 관심 있는 산업 분야를 최대 3개 골라주세요.** *(복수, 최대 3)*
`반도체·IT / 2차전지·에너지 / 바이오·헬스케어 / 금융 / 소비재·유통 / 엔터·콘텐츠 / 방산·중공업 / 특별히 없음`
→ 가명 종목의 **섹터 프로파일**로 반영 *(실존 기업이 아닌 가상 기업으로 생성)*

**D2. 이 서비스에서 가장 배우고 싶은 것은?**
`레버리지 상품의 위험 / 손절 타이밍 / 분산투자 / 급락장 대응 / 뉴스에 휘둘리지 않는 법 / 전반적인 투자 감각`
→ **학습 목표(Learning Objective)** — 세션 종료 조건과 채점 가중치 결정

**D3. 한 번에 얼마나 시간을 쓸 수 있나요?**
`5분 / 15분 / 30분 / 1시간 이상`
→ **세션 길이 및 시뮬레이션 배속(가상 거래일 수)** 결정

## 🔧 프로파일 → 시나리오 파라미터 변환 (LLM 입력 스키마 예시)

```json
{
  "profile": {
    "experience": "basic",
    "untried_products": ["leverage"],
    "max_loss_experienced": "5-20%",
    "risk_appetite": 4,
    "behavior_tags": ["averaging_down", "boredom_intolerant"],
    "declared_stoploss_habit": "sometimes",
    "declared_max_position_pct": 50,
    "info_dependency": "community",
    "sectors": ["semiconductor", "bio"],
    "learning_objective": "leverage_risk",
    "session_minutes": 15
  }
}
```

**LLM(시나리오 오케스트레이터) 출력 예시**
```json
{
  "scenario_name": "잔잔한 바다, 녹는 원금",
  "narrative": "지수는 3개월간 ±4% 박스권에 머물지만, 커뮤니티에서는 매일 급등 기대가 반복된다",
  "regime": "sideways_high_intraday_vol",
  "drift": 0.0, "daily_vol": 0.035, "jump_intensity": 0.05,
  "trading_days": 60,
  "assets": [
    {"alias": "가온반도체", "sector": "semiconductor", "type": "equity"},
    {"alias": "가온반도체 2X 레버리지", "sector": "semiconductor", "type": "leveraged_etf", "multiplier": 2}
  ],
  "agent_mix": {"momentum": 0.4, "contrarian": 0.2, "institutional": 0.2, "herd": 0.2},
  "news_density": "high",
  "target_concepts": ["volatility_decay", "averaging_down"],
  "scoring_weights": {"stoploss_adherence": 0.3, "position_sizing": 0.3, "leverage_exposure_time": 0.4}
}
```
> **이 시나리오가 노리는 것:** `boredom_intolerant` + `averaging_down` 성향의 사용자를
> **횡보장 + 고변동성 + 레버리지** 조합에 넣어, **변동성 잠식**을 몸으로 겪게 한다.
> 수익률로는 설명되지 않고, **오직 겪어야만 이해되는 개념.**

## 💡 디브리핑 연결 — 온보딩 응답이 만들어내는 문장

> 이 문항 설계의 최종 목적은 아래와 같은 **개인화된 지적**을 가능하게 하는 것이다.

- *"당신은 손절선을 '가끔 정한다'고 답했습니다. 이번 세션에서 손절선을 정한 것은 7건 중 2건, 그중 실제로 지킨 것은 0건입니다."*
- *"한 종목 최대 비중을 50%라고 답하셨지만, 실제로는 3일차에 자산의 82%를 단일 레버리지 상품에 넣었습니다."*
- *"기초자산은 60일 뒤 +1.2%로 마감했습니다. 그런데 당신이 보유한 2배 레버리지 상품은 -11.4%였습니다. 이것이 변동성 잠식입니다."*
- *"커뮤니티 여론을 주로 참고한다고 하셨습니다. 이번 세션에서 커뮤니티 글이 올라온 뒤 3분 이내에 낸 주문은 총 9건이었고, 그중 7건이 손실로 끝났습니다."*

🔴 **미팅 확인 사항:** 12문항이 온보딩 이탈률 대비 과한지 검토. 축소 시 **SECTION C(3문항)는 유지 필수** — 디브리핑의 핵심 대조 근거이기 때문.

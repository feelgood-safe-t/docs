# UI/UX 화면 흐름 및 와이어프레임 v0.6
### AI 레버리지 안전투자 훈련 플랫폼 「Safe-T」

> **기준:** `spec/README.md` — 캐주얼 판단 모드 (PoC 범위)
> **협업:** 기획·UX 담당 ↔ 프론트엔드 담당
> **전제:** 모바일 웹 우선(Mobile-first), 데스크톱 반응형. 설치·로그인 마찰 최소화
> **심사 관점:** 심사위원은 **배포 URL에 처음 들어와 짧은 시간 안에 가치를 이해**해야 한다. 온보딩이 곧 심사 시연이다.
>
> v0.6 = 스펙 반영본. 실전형 모의투자(매수·매도·비중·손절) 화면은 전부 제거하고 UP/DOWN 판단 모드로 재작성.

---

## 0. 설계 원칙 5가지

| # | 원칙 | 구현 함의 |
|---|---|---|
| **U1** | **3클릭 안에 평가가 시작돼야 한다** | 회원가입 없이 익명 세션. 심사위원용 **프리셋 프로파일 + 바로 시작** 경로 필수 |
| **U2** | **수익률은 주인공이 아니다** | 적중률·예상 수익률은 결과 화면에서만, 작게. **과정 점수를 크게.** 랭킹 보드 없음 |
| **U3** | **위험은 숫자가 아니라 감각으로 전달한다** | 레버리지 자산을 UP으로 둔 동안 상단 경고 밴드 상시 노출, 노출 시간 누적 표시 |
| **U4** | **모든 생성 콘텐츠에 라벨** | 뉴스·공시·커뮤니티 카드에 `AI 생성 시뮬레이션 콘텐츠` 배지 상시 노출 |
| **U5** | **정보 출처가 시각적으로 구분돼야 한다** | 공시 / 기사 / 커뮤니티를 **색·아이콘·라벨로 명확히 분리**하고 **열람 행동을 로깅**한다 → 정보 출처 검증(15점) 채점 근거 |

## 1. 전체 화면 흐름

```
 [L] 랜딩
  │  "실제 돈을 잃기 전에, 먼저 겪어보세요"
  │  ├─▶ [바로 체험하기] ── 익명 세션 즉시 시작 (심사위원 동선)
  │  └─▶ [소개 보기]
  ▼
 [O] 성향 설문 (10문항 · 약 80초)
  │  카드형 1문항 1화면 · 진행률 바
  │  마지막 문항 = 감수 가능한 위험 수준 ★ 채점 기준선
  ▼
 [P] AI 성향 분석 결과
  │  성향 요약 / 강점 / 취약점 / 우선 학습 항목
  ▼
 [S] 시나리오 배정 + 평가 시간 선택
  │  AI가 고른 시나리오 + 배정 이유
  │  평가 시간: 6 / 12 / 30 / 60 / 120분
  ▼
 [B] 브리핑
  │  등장 자산 3종 / 밝힌 위험 한도 재확인 / 조작 방법 안내
  ▼
 [T] 평가 화면 ◀── 서비스의 심장
  │  자산 3개 · 차트 · 수급 · 참고지표 · 정보 피드 · UP/DOWN
  │  서버 시간 60배속 진행 (정지 불가)
  │  ├─▶ [X] 이탈 → 재접속 시 [T2] 이어하기
  │  └─▶ [E] 이벤트 배너 (급락·공시·서킷브레이커)
  ▼
 [Q] 기초 개념 퀴즈 (3~5문항 · 5점)
  ▼
 [R] 결과 보고서
  │  1) 총점과 항목별 점수
  │  2) 밝힌 위험 한도 vs 실제 ★ 가장 강한 화면
  │  3) 판단 변경 타임라인 + 확인한 정보 출처
  │  4) 가장 적절했던 판단 / 가장 위험했던 판단
  │  5) 반복된 행동 패턴 · 개선 습관 · 추천 후속 학습
  ▼
 [C] INVEST PASS 발급 (70점 이상)
     인증 코드 · 평가 시간 · 시나리오 유형 · 최종 점수 · 발급일 · 검증 페이지
     ※ "공인 금융 자격 아님" 고정 안내문
```

```
│  │        ╲              │  │

│  수급  개인 +  외인 −  기관 −│

│  참고지표                    │

│  환율 +1.2  BTC −2.4        │
├─────────────────────────────┤
│ 정보 피드      AI 생성 시뮬레이션│
│ ┌─────────────────────────┐ │
│ │ 📑 공시  가온소재        │ │ ← U5 출처별 색·아이콘 구분

│ ├─────────────────────────┤ │
│ │ 📰 기사  "업계 전반 위축"│ │

│ └─────────────────────────┘ │
├─────────────────────────────┤
│  가온소재 2X 에 대한 판단     │
│  ┌──────────┐ ┌──────────┐  │
│  │  ▲ UP    │ │  ▼ DOWN  │  │
│  └──────────┘ └──────────┘  │
│  확신도  [낮음][보통][높음]  │
│  근거    [가격][수급][공시]  │
│          [뉴스][커뮤][거시]  │
│          [직감]              │
└─────────────────────────────┘
```

**필수 동작**
- 판단은 **언제든 변경 가능**. 변경하지 않으면 직전 판단이 유지된다
- 확신도·근거 태그는 **선택 사항**이되, 입력하면 채점 항목 2개(각 5점)에 반영됨을 안내
- 정보 카드 **열람(탭·펼침) 이벤트를 로깅** — 정보 출처 검증(15점)의 유일한 근거
- 배속 제어·일시정지 **없음** (서버 시간 기준 진행)

🔴 **프론트 결정 필요**
- 자산 3개 표시 방식 — 탭 전환 vs 세로 스택 vs 스와이프 캐러셀
- 차트 라이브러리 및 갱신 방식(WS vs 폴링). 60배속이라 틱 빈도 설계 필요
- 정보 피드 신규 도착 시 알림 방식 (배지 / 토스트 / 자동 스크롤)

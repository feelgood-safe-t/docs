## ⚠️ 엔진/프론트 파트에 전달할 리스크

1. **모델 ID 확인** — 공유된 `https://huggingface.co/Qwen/Qwen3.8-27B` 는 실존하지 않는 ID로 보임. 실제 사용할 모델 확정 필요.
2. **LLM 호출 시점** — 평가 진행 중에는 LLM을 호출하지 않는 구조를 권장. 콘텐츠는 시나리오 제작 시 **사전 배치 생성 후 검수**해 캐시하고, 성향 분석·행동 분석·보고서만 평가 전후 1회씩 호출 → 지연·비용·재현성이 동시에 해결됨.
3. **재현성** — 스펙 필수 비기능 조건. 동일 시나리오·동일 판단 기록 → 동일 점수. 시나리오·평가 규칙·프롬프트 **버전 기록** 필요.
4. **심사자용 데모 프리셋** — 성향 설문 10문항을 심사위원이 매번 채우게 하면 안 됨. **프리셋 프로파일 + 짧은 평가 시간 + 완료된 샘플 보고서** 경로 필요.
5. **가용성 + 세션 지속성** — 9/7 11:00~9/11 23:59 무중단. 평가 상태가 서버에 저장되어야 하므로(스펙 필수 조건) 재시작 시 진행 중 평가가 살아남는지 확인 필요.

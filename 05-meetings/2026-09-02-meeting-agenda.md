## ⚠️ 엔진/프론트 파트에 전달할 리스크

1. **모델 ID 확인** — 공유된 `https://huggingface.co/Qwen/Qwen3.8-27B` 는 실존하지 않는 ID로 보임. 실제 사용할 모델 확정 필요.
2. **LLM 호출 비용/지연** — AI 에이전트가 매 틱마다 LLM을 호출하면 60거래일 시뮬레이션이 성립하지 않음.
   → 제안: **에이전트 의사결정은 규칙 기반 + 파라미터**로 두고, LLM은 **① 시나리오 생성 ② 뉴스 생성 ③ 디브리핑** 3곳에만 사용. 심사자가 보는 가치는 이 3곳에 다 있음.
3. **결정성(재현성)** — 심사자가 같은 시나리오를 재현할 수 있도록 **시드 고정** 필요. 기능명세서 5번(MVP 검증 방법)에 "샘플 입력값과 예상 결과"를 써야 하므로 필수.
4. **심사자용 데모 프리셋** — 온보딩 12문항을 심사위원이 매번 채우게 하면 안 됨. **프리셋 프로파일 + 바로 시작** 경로 필요.
5. **가용성** — 9/7 11:00~9/11 23:59 무중단. 자체 서버 단일 장애점 회피 방안.

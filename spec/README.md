# Safe-T

## 프로젝트 정의

**Safe-T**는 실제 돈을 투자하기 전에 고위험 투자 상황을 경험하고, 사용자의 위험 대응 능력을 평가하는 AI 기반 모의투자 교육 플랫폼이다.

사용자의 최종 수익이 아니라 다음과 같은 **투자 의사결정 과정**을 평가한다.

- 어떤 정보를 확인했는가
- 어느 시점에 판단했는가
- 위험이 커졌을 때 판단을 수정했는가
- 레버리지와 변동성을 적절히 인식했는가
- 일관된 기준으로 의사결정을 내렸는가
- 등

평가를 통과한 사용자에게는 플랫폼 자체 교육 인증인 `INVEST PASS`를 발급한다.

`INVEST PASS`는 공인 금융 자격이 아니며, 장기적으로 금융사·교육기관·관계 부처가 활용할 수 있는 투자자 안전교육 인증으로 확장하는 것을 목표로 한다.

## 제품 구조와 PoC 범위

Safe-T의 최종 서비스는 두 가지 모드로 구성한다.

| 모드 | 내용 | PoC 포함 여부 |
|---|---|---|
| 캐주얼 판단 모드 | 시장 정보를 관찰하고 자산별 Up/Down을 선택해 판단 과정을 평가 | 포함 |
| 실전형 모의투자 모드 | 가상 자금으로 매수·매도·비중 조절·손절·레버리지 등을 수행 | 제외, 추후 개발 |

이번 PoC에서는 **캐주얼 판단 모드**만 구현한다.

캐주얼 모드는 실전형 모의투자의 단순 축소판이 아니라, 실전형 모드에서도 필요한 다음 기능을 먼저 검증하는 핵심 서브셋이다.

- 사용자 성향 분석
- 맞춤 시나리오 배정
- 시장 상황 재생
- 시점별 판단 기록
- 투자 과정 평가
- AI 분석 보고서
- 교육 인증 발급

또한 복잡한 주문 없이 누구나 게임처럼 참여할 수 있어, 대중 대상 위험투자 교육 모드로도 독립적인 가치가 있다.

실전형 모드는 서비스 화면에 `준비 중` 등으로 표시한다.

```text
성향 설문

→ 과정 중심 평가
→ AI 분석 보고서
→ 통과 시 INVEST PASS 발급
```

## PoC 기능 범위

### 사용자 성향 분석

사용자는 평가 시작 전 다음 항목에 응답한다.

- 투자 경험
- 위험 선호도
- 레버리지 이해도
- 손실 대응 성향
- 정보 출처 검증 습관
- 관심 자산 및 산업
- 평가 시 감수 가능한 위험 수준

AI는 응답을 기반으로 다음 결과를 생성한다.

- 사용자 성향 요약
- 주요 강점
- 주요 취약점
- 우선 학습 항목
- 적합한 시나리오 추천

AI는 사전에 검수된 시나리오 목록 안에서만 시나리오를 선택한다.

### 시나리오 구성

각 시나리오는 실제 과거 시장 구간을 기반으로 제작하되, 다음 정보를 모두 가명화한다.

- 종목명
- 기업명
- 인물명
- 날짜
- 뉴스 제목과 본문
- 절대 가격

가격은 시작 시점을 기준으로 정규화할 수 있다.

```text
정규화 가격 = 실제 가격 / 시작 가격 × 100
```
100 이외 다른 시작값으로 가중해서 랜덤하게 시작 가능하다.

각 평가에는 동일한 시점의 가상 자산 3개를 제공한다.

- 일반 자산
- 레버리지 자산 (인버스 포함) 또는 상대적으로 안정적인 자산
- 레버리지 자산 (인버스 포함)

과거 데이터에 적합한 레버리지 자산이 없을 경우, 기초자산의 수익률을 기반으로 가상 레버리지 자산을 생성한다.

각 시나리오는 다음 데이터를 포함한다.

- 가격 OHLC
- 거래량
- 개인·외국인·기관 매매 동향
- 관련 뉴스와 공시
- 커뮤니티 게시물
- 변동성 이벤트
- 금·채권·환율·비트코인 등 참고지표
- 시나리오별 평가 규칙

캔들과 시장 데이터는 AI가 생성하지 않으며, 고정된 히스토리 데이터로 정규화 및 가명화 후 재생한다.

### 평가 시간과 시장 진행

지원 평가 시간은 다음과 같다.

- 6분
- 12분
- 30분
- 60분
- 120분

시장 시간은 실제 서비스 시간보다 **60배 빠르게 진행**한다.

```text
서비스 1분 = 시장 시간 60분
```

평가는 서버 시간을 기준으로 계속 진행된다.

- 사용자는 평가 중 화면을 나갈 수 있다.
- 다시 접속하면 현재 시점부터 이어서 참여한다.
- 접속하지 않은 동안에도 시장과 이벤트는 진행된다.
- 사용자가 내린 기존 판단은 다음 변경 시점까지 유지된다.

해커톤 시연에서는 6분 또는 12분 평가를 기본으로 사용한다.

### 캐주얼 판단 인터페이스

사용자는 각 자산에 대해 언제든지 다음 중 하나를 선택할 수 있다.

- `UP`: 해당 자산이 상승할 것으로 판단
- `DOWN`: 해당 자산이 하락하거나 위험하다고 판단

거래 액션은 Up/Down으로 제한한다. 분석 정확도를 높이기 위해 선택 시 다음 보조정보를 받을 수 있다.

- 확신도: 낮음 / 보통 / 높음
- 판단 근거 태그: 가격, 수급, 공시, 뉴스, 커뮤니티, 거시지표, 직감

긴 문장 작성은 요구하지 않는다.

화면은 다음 요소로 구성한다.

- 가명화된 자산 3개
- 캔들 차트
- 거래량 및 수급
- 시장 참고지표
- 뉴스·공시·커뮤니티 피드
- 현재 판단 상태
- 큰 Up/Down 버튼
- 평가 종료까지 남은 시간

모든 선택은 다음 정보와 함께 기록한다.

```text
사용자
시나리오
자산
선택 방향
(Optional) 확신도
(Optional) 판단 근거 태그
선택 시각
당시 시장 시점
당시 가격과 변동성
열람한 뉴스와 출처
직전 판단
```

### AI 기반 결과 해석

캐주얼 모드에는 실제 주문과 자금 배분이 없지만, 결과 분석을 위해 내부적으로 다음 의미를 내포한다(AI가 알아서 이를 내포하고 있음을 인지하고 분석한다).

- `UP`: 해당 자산에 가상 노출
- `DOWN`: 해당 자산의 노출 제거 및 현금 보유
- 명시적인 인버스 자산이 있는 경우에만 하락 방향 수익 반영
- 여러 자산을 Up으로 선택하면 자산 조합에 따라 해석이 달라질 수 있음
- 레버리지 자산에는 해당 배수를 적용하는 효과를 내포

이 모델은 실제 투자 결과가 아니라 다음 교육용 참고지표를 계산하기 위한 용도다.

- 예상 누적 수익률
- 예상 최대 낙폭
- 예상 최대 유효 레버리지
- 자산 집중도
- 위험 구간 노출 시간

### AI 합성 콘텐츠

AI는 실제 과거 사건의 핵심 사실을 기반으로 가상 기업의 콘텐츠를 생성한다.

제공 콘텐츠는 다음과 같이 구분한다.

- 공식 공시
- 언론 기사 (뉴스))
- 익명 커뮤니티 게시물

생성 원칙은 다음과 같다.

- 실존 기업·인물·종목명 사용 금지
- 실제 뉴스 원문 복사 금지
- 시나리오에 정의된 사실만 사용
- 시나리오상 미래 데이터는 모르는 채로, 현재 진행상황 기반으로 생성
- 동일 시나리오 안에서 가명 일관성 유지
- 모든 콘텐츠에 `AI 생성 시뮬레이션 콘텐츠` 표시
- 실제 투자 추천 문구 생성 금지

## 과정 평가

총점은 100점이며, 최종 수익률은 점수에 직접 반영하지 않는다.

| 평가 항목 | 점수 | PoC 측정 기준 |
|---|---:|---|
| 위험 한도 준수 | 20 | 사전에 밝힌 위험 수준과 실제 판단의 일치 여부 |
| 레버리지 통제 | 20 | 레버리지 자산 선택과 변동성 확대 후 대응 |
| 정보 출처 검증 | 15 | 공시·기사·커뮤니티의 구분 및 확인 행동 |
| 자산 집중도 | 10 | 표준 가상 포지션의 특정 자산 편중 |
| 손실 이후 행동 | 10 | 잘못된 판단 이후 추격·반복·충동적 전환 여부 |
| 판단의 일관성 | 10 | 동일한 정보에서 무작위로 방향을 반복 변경하는지 |
| 전망 및 확신도 | 5 | 방향 판단과 확신도의 보정 수준 |
| 기초 개념 퀴즈 | 5 | 레버리지·변동성·정보 출처 관련 문항 |
| 판단 근거의 구체성 | 5 | 선택한 정보와 판단 근거의 연결성 |
| **합계** | **100** |  |

개별 항목들을 AI가 점수화해 누계한다.

### 통과 조건

- 총점 70점 이상

방향 적중률과 예상 수익률은 결과 보고서에 표시하지만, 높은 수익이나 높은 적중률만으로 통과할 수 없다.

최종 점수와 합격 여부는 규칙 기반 평가 엔진이 결정한다.
(누계 후 threshold를 넘는지 여부)

## AI 역할

| 역할 | 처리 내용 |
|---|---|
| 성향 분석 | 설문 응답을 강점·취약점·학습 항목으로 정리 |
| 시나리오 배정 | 검수된 시나리오 중 사용자에게 적합한 항목 추천 |
| 콘텐츠 생성 | 가명화된 공시·기사·커뮤니티 콘텐츠 생성 |
| 행동 분석 및 이유 추정 | 판단 시점, 정보 열람, 방향 변경 패턴 분석, 당시 노출된 정보를 기반으로 판단 이유 추정 |

AI가 담당하지 않는 영역은 다음과 같다.

- 캔들 및 시장 데이터 생성
- 시장 시간 진행
- 최종 점수 계산
- 합격 여부 결정

## 결과 보고서와 인증

### 결과 보고서

평가 종료 후 다음 내용을 제공한다.

- 총점과 항목별 점수
- 방향 판단 적중률
- 표준 가상 포지션 기준 예상 수익률
- 예상 최대 낙폭
- 예상 최대 레버리지
- 판단 변경 타임라인
- 확인한 정보 출처
- 가장 적절했던 판단
- 가장 위험했던 판단
- 반복된 행동 패턴
- 개선이 필요한 투자 습관
- 추천 후속 학습

### INVEST PASS

통과 시 평가 시간별 인증을 발급한다.

예시:

```text
INVEST PASS L1
12-Minute Leverage & Volatility Assessment
```

인증서에는 다음 내용을 포함한다.

- 인증 코드
- 평가 시간
- 시나리오 유형
- 최종 점수
- 발급일
- 검증 페이지 주소
- 민간 교육 인증 안내

고정 안내문:

> 본 인증은 Safe-T가 발급하는 자체 교육 인증이며, 공인 금융 자격 또는 실제 투자 적격성을 의미하지 않습니다.

## PoC 제외 범위

다음 기능은 이번 PoC에서 구현하지 않는다.

- 실제 돈 입출금
- 증권사 계좌 연동
- 실시간 주가
- 실제 종목 추천
- 가상 자금 기반 매수·매도 주문
- 사용자 직접 비중 설정
- 손절매·이익실현 주문
- 공매도·옵션
- 사용자 간 수익률 경쟁
- 공식 금융 자격 발급
- AI가 자유롭게 생성하는 시장 가격과 무한 시나리오

가상 자금 기반 실전형 모의투자는 Safe-T의 후속 `실전형 모드`로 개발한다.

### 필수 비기능 조건

- 비록 AI에 기반하지만, 동일한 시나리오와 판단 기록에는 최대한 동일한 점수가 나와야 한다.
- 평가 진행 상태는 서버에 저장되어 재접속 후 이어갈 수 있어야 한다.
- 실제 종목·기업·인물 정보가 사용자 화면에 노출되지 않아야 한다.
- 시나리오, 평가 규칙, AI 프롬프트 버전을 기록해야 한다.
- 모든 결과에 투자 추천이 아니라 교육용 시뮬레이션임을 표시해야 한다.
- PoC에서는 실명, 실제 계좌, 실제 자산 규모를 수집하지 않는다.
